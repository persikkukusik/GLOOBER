How to get your free API key
  1. Click the button below to open the Groq Console
  2. Sign in or create a free account
  3. Click Create API Key, give it any name you like
  4. Copy the key that appears (starts with gsk_)
  5. Paste it into the field below and click Save

WARNING: This app runs entirely in your browser. Your API key is stored locally and can be accessed by scripts or browser extensions running on this page. Do not use sensitive or high-value keys to stay safe, thank you.

What is Gloober?

Gloober is a Windows 98–styled AI roleplay chat application that runs entirely in your browser. Create AI characters with custom personalities, define your own user personas, set immersive scenes, and chat with them — all powered by the Groq API for fast, free inference.

Features
  • Unlimited characters, personas, and scenes
  • Editable chat messages and conversation titles
  • AOL Instant Messenger mode for retro vibes
  • Custom chat backgrounds per conversation or scene
  • Full data import/export (JSON) — your data, always yours
  • Fully offline after first load — no server, no tracking
Legal & Disclaimer

Gloober is an independent, community-made client and is not affiliated with, endorsed by, or sponsored by Groq, Inc. in any way. All AI responses are generated by Groq's API using models you select. You are responsible for your API key usage and any content generated. This app stores all data locally in your browser — nothing is sent to any server except your Groq API calls.
